PHASE 1 — Finish the core farming-sim loop (HIGHEST impact)
-----------------------------------------------------------------------
1A. CRAFTING / COOKING / PROCESSING  (biggest missing system)
    - Currently ZERO item transformation; everything sells raw.
    - Add placeable workstations (Stove, Preserve Jar, Brewing Kettle).
    - New CraftingManager with ~10 recipes combining 2-3 ingredients.
    - Buffs: Onigiri +20% stamina regen; Tomato sauce sells x1.5; etc.
    - Makes buildings functional (fixes "buildings are cosmetic").
    [DONE 2026-08-31] CraftingManager + 3 workstations added to build
    palette (crafting_stove / preserve_jar / brewing_kettle), E-interact
    to open filtered recipe panel. 10 recipes. New products + sell prices.
    [DONE 2026-09-01] Enemy materials woven into brewing recipes
    (ruou_tang, tinh_duoc) closing the drop->craft->sell loop. Crafted
    foods added to the eat system; Xoi Gac gives a +20% stamina regen
    buff for 120s (the planned "Onigiri"-style buff). More buffs/heal
    tuning deferred to Phase 3 balance tuning.

1B. ENEMY MATERIAL DROPS + DODGE-ROLL
    - Enemies currently drop nothing.
    - Drop materials (demon_horn, dark_essence, bone) on Die() ->
      feed crafting/upgrades.
    - Add dodge-roll with i-frames (stamina cost) in PlayerController
      -> skill ceiling for the boss fight.
    [DONE 2026-08-31] Materials drop on Die() (boss: demon_horn +

PHASE 2 — Long-term progression
-----------------------------------------------------------------------
2A. SKILL / XP SYSTEM  (new SkillManager, 2 tracks, levels 1-5)
    - No skill/XP system exists. Add SkillManager as a MonoSingleton
      modeled on KarmaManager (level/current fields + GetSaveData/LoadSaveData).
    - 2 tracks, each 1-5: Farming, Fishing.  (Combat EXCLUDED: player already
      grows via the praying minigame — Karma/MaxKarma buffs.)
    - XP hooks already exist:
        farming  -> ToolManager.cs:~962 harvest path (field.CropType + qty)
        fishing  -> FishingController.cs:346 OnCatchFish (fishType)
    - 2A.1 MINIMAL: levels only — each track levels via XP, each level-up
      grants a permanent passive stat bump (farming: +stamina restore on
      harvest; fishing: +reel speed / lower flop chance). Persist via
      PlayerPrefs JSON like KarmaManager. [implement first, reviewable alone]
    - 2A.2 FULL: perks at levels 2/4 per track + a HUD skill panel (karma-bar
      pattern in UIManager.HUD.cs) listing track + XP + next level, opened
      from a hotkey.
    - SaveManager integration (new SkillSaveData; no combat track).
    [DONE 2026-09-01: 2A.1 — SkillManager (2 tracks, lv1-5, slot-saved),
     farming XP on harvest + cheaper farm-tool stamina; fishing XP on catch
     + lower flop chance + faster reel.]
    [DONE 2026-09-01: 2A.2 — perks L2/L4 auto-granted (farm L2 bonus crop,
     farm L4 all-tool -25% stamina; fish L2 double catch, fish L4 +15% reel);
     skill panel (K key, karma-bar pattern) showing level/XP/perks.]

2B. FUNCTIONAL BUILDINGS
    - Placed buildings are cosmetic (BlueprintState/CompleteBlueprint spawn
      entity named by def.Name under _worldRoot; find by name).
      Phase 1 already made workstations functional; remaining gaps:
    - well: any crop in a radius is auto-watered each morning (skip manual
      watering) — fixed radius, keep simple.
    - watchtower: shows a "danger / enemy near" warning marker when enemies
      spawn within range; nearby enemies move slower inside its radius.
    - fence: gets its own HP; enemy damage hits fence parts instead of the
      player (BuildingPartState.CurrentHealth already exists); player is safe
      while a fence part remains.
    - Persist per-building behavior flags without breaking existing saves
      (new optional fields, default off).

2C. NPC FRIENDSHIP   (Monk / Librarian / Chef / FishShop, 0-5 hearts)
    - All NPCs are MonoSingletons like WifeNPC; add a centralized
      FriendshipManager storing hearts per NPC (PlayerPrefs JSON).
    - Daily talk +1 heart-point (cap per day, like WifeNPC _lastTalkDay),
      gifts via E-interaction deposit, heart-up messages + per-heart rewards:
      heart 2 = shop discount / recipe unlock; heart 3 = unique item or new
      dialog line; heart 5 = special scene.
    - FULL: net-new per-heart gift/dialog content for each of the 4 NPCs
      (Vietnamese + English), plus heart meter in a friendship panel.
    - Save/load a new FriendshipSaveData.

Split: 2A.1 -> 2A.2 -> 2B -> 2C as separate commits, reviewable & stoppable
between each.
